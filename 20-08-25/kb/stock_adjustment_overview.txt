Stock Adjustment Overview

Stock adjustment is a process that allows warehouse operators to correct inventory levels in the system to match physical stock on hand.
This could be due to reasons like damage, shrinkage, counting discrepancies, or manual audits.

Business Flow:
1. Operator initiates a stock adjustment request through the HHT device or WMS UI.
2. Adjustment reason is selected (e.g., Damage, Excess, Shortage).
3. System checks item eligibility and open stock positions.
4. Adjustment quantity is validated against available inventory.
5. Adjustment is posted, triggering inventory update and audit logging.
6. Relevant parties are notified, and the item’s updated quantity is reflected across downstream processes.

Functional Flow:
1. User logs into the system (HHT or Web UI)
2. Selects "Inventory Adjustment"
3. Enters or scans:
   - Item
   - LPN (if applicable)
   - Location
4. System fetches current inventory details
5. User selects:
   - Adjustment Type: Increase / Decrease
   - Quantity
   - Reason Code (Damage / Found / Audit Correction)
6. System validates input:
   - Quantity can't be negative
   - Location should be valid
7. Inventory updated in WMS DB
8. Adjustment record logged in inventory history table
9. Optional: triggers inventory sync to ERP
