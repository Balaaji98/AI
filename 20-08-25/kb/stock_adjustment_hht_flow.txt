Stock Adjustment via HHT

Flow from Handheld Terminal (HHT) to WMS backend:

1. Operator logs into HHT and selects "Stock Adjustment" module.
2. Scans item barcode and enters quantity to adjust.
3. Selects reason from dropdown: "DAMAGED", "MISSING", "EXCESS".
4. Submits adjustment.

Sample Payload sent to backend (JSON format):
```json
{
  "item_id": "100145",
  "adjust_qty": -10,
  "reason": "DAMAGED",
  "location": "RACK-A2-B1",
  "user_id": "HHT_OPR_23",
  "timestamp": "2025-08-06T20:21:00+05:30"
}
```

Backend endpoint: `/api/stock-adjustment/submit`
This API triggers `INV_STK_ADJ_PKG.process_adjustment()` and returns success/failure message.
